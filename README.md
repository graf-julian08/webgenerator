# Web Generator Engine

Multi-Modell Generator fuer KI-gestuetzte Webanwendungen und E-Commerce Systeme.

## Funktionalitaeten
- Uebersichtlicher Code und strukturierte Aufteilung der Komponenten.
- Einfache Integration und Anpassung an bestehende Systeme.

## Nutzung
Starte die Generierung mit `node build_app.js`.
